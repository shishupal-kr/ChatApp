About ChatApp

ChatApp is a simple real-time messaging application focused on one-to-one conversations. It is designed to provide a clean chat experience with message delivery, online presence, unread counts, and profile-based navigation.

This application is currently available as a web app. It is built using Spring Boot, WebSocket, JWT authentication, and a frontend made with HTML, CSS, and JavaScript.

Version: 1.0.0
